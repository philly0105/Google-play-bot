Clash Farmer PC
===============

Clash Farmer plays Clash of Clans for you in Google Play Games on this PC: it attacks and
collects loot while you do other things.

Read this first: using a bot breaks Supercell's terms of service, and Supercell can ban the
account for good. Only use it on an account you are ready to lose.


What you need
-------------
- Windows 10 or 11, 64-bit.
- Google Play Games for PC, with Clash of Clans installed and signed in.
- Clash of Clans set to English (Settings > Language). The bot reads the game's text.


Install
-------
1. Right-click the zip, choose Properties, tick Unblock if it is there, and click OK.
2. Right-click the zip and choose Extract All. Put the folder anywhere you like, for example
   Documents. Don't run it from inside the zip.
3. Open the ClashFarmerPC folder and double-click ClashFarmerPC.exe.
4. Windows may say "Windows protected your PC". The app isn't signed, so this is expected:
   click More info, then Run anyway. You only do this once.
   If Smart App Control blocks it with no Run anyway button, this PC can't run unsigned apps.


First run
---------
1. Open Clash of Clans in Google Play Games.
2. In Clash Farmer, open Setup and fix anything it marks in red or amber.
3. Calibrate when Setup asks you to. Press "Start from the standard positions", then check
   each troop card against your own battle tray, press "Not in my army" on any hero or spell
   you don't have, and press "Save calibration".
4. Start one supervised attack and watch it all the way through before you leave it alone.

Closing the window keeps Clash Farmer running in the notification area (next to the clock).
To stop it, right-click its icon there and choose Quit.


While it plays
--------------
- Keep the PC unlocked with the screen on. Locking it, or letting the screen turn off, stops
  the run, and Clash Farmer tells you why.
- You can use the PC meanwhile: Clash can sit behind other windows or be minimized, and the
  mouse and keyboard stay yours. Don't play Clash full screen.
- If Setup says the game is too small, do what it says: make Clash's window larger or maximize
  it, or move it to a larger screen. A maximized window is fine; only full screen is not.
- Don't close Clash's window while Google Play Games is still open. If you do, restart the PC
  before the next run: until then the game ignores the bot's taps.
- It never spends gems and never signs you in or out.
- To have runs stop once gold and elixir are full, enter your storage sizes: Setup, Edit
  settings, the capacity boxes. Without them a run keeps attacking until its limit.


Help
----
Setup has an "Open logs folder" button. If something goes wrong, send the newest files from
that folder (desktop.log is the main one) to whoever gave you Clash Farmer.

To update, quit Clash Farmer, delete the old folder and extract the new zip. Your settings are
kept in %LOCALAPPDATA%\ClashFarmerPC. To remove it completely, delete both.
